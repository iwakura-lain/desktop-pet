## Key PlayerSettings for Transparent Window Desktop Pet

Open **Edit → Project Settings → Player** in Unity Editor and configure:

### Product Information
| Field | Value |
|---|---|
| Company Name | (your name) |
| Product Name | desktop-pet |
| Version | 0.1.0 |

### Resolution and Presentation (Windows)
| Setting | Value |
|---|---|
| Fullscreen Mode | Windowed |
| Default Screen Width | 256 |
| Default Screen Height | 256 |
| Resizable Window | ☐ (unchecked) |
| Run in Background | ☑ (checked) |

### Other Settings
| Setting | Value |
|---|---|
| Scripting Backend | IL2CPP |
| Api Compatibility Level | .NET Standard 2.1 |
| Allow Unsafe Code | ☑ (required for some P/Invoke patterns) |

### URP Transparent Background
In your URP Asset (Assets/Settings/UniversalRenderPipelineAsset.asset):
- HDR: Off (not required for 2D pet)

In the Camera component:
- Background Type: Solid Color → Black (#000000, A=0)

The `WindowManager.cs` script uses `SetLayeredWindowAttributes` with colour key
`0x000000` (black) to punch through the window background at runtime.
